# Realtor Mock Website

This is a mock website for a real estate agency, designed to showcase property listings and provide information about the services offered. The website is built using modern web technologies and follows best practices for responsive design.

## Features

- Responsive design for all devices
- Property listings with images and descriptions
- Contact form for inquiries
- About page with company information

## Search Functionality

The website includes a search functionality that allows users to filter property listings based on various criteria such as location, price range, property type, and number of bedrooms. This feature enhances user experience by enabling visitors to quickly find properties that meet their specific needs.
There isn't any backend integration for the search functionality; it is implemented using client-side JavaScript to filter through a predefined list of properties, so in this case there is not a location based filter.
